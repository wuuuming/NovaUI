- **元素树拥有元素。** 应用持有 `Id`，`Id` 会被校验：元素删掉后它的 `Id` 不再指向任何东西。
- **主人把句柄放在字段里。** 视图关闭时丢掉自己的结构体，随之丢掉它持有的每个定时器、ticker、任务和订阅。不需要过滤过期结果，也不需要比较 epoch。
- **`Ui` 只持有句柄的弱引用**，所以丢掉的句柄就直接消失。
- **图像是共享的。** `ImageHandle` 经过驻留并带引用计数：两个元素显示同一张图只占一张纹理，最后一个放手时释放。
- **每个缓存都写明上限**和先丢什么：字形图集（16 页，丢最久未用的页）、文字排版、图像。
- **每帧路径上不分配内存。** tick、绘制和命中测试复用主人保存的缓冲区。

## UI 线程外的工作

- `ui.spawn(priority, work, done)` 在一个小工作线程池上运行 `work`，并把 `done(result)` 作为消息投递。`Visible` 工作先于 `Background` 工作；后台队列满时拒绝（`None`），调用者稍后再请求。`work` 拿到一个 `Cancel`，可以知道它的 `Task` 是否已被丢掉。
- `ui.queue(capacity)` 是同一批工作线程上的串行队列：`latest` 替换待办的工作，`try_background` 在队列满时被拒绝。
- `ui.waker(msg)` 是给应用自有线程用的 `Send` 句柄：`wake` 会在下一轮投递 `msg`。
- 结果按每轮半个刷新周期的预算投递；其余留到下一轮，而下一轮会立即运行。
