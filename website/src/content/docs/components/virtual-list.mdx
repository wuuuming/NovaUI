`widgets::list::VirtualList` keeps the rows in view and moves them as the offset changes, without
layout. `sync(ui, count, make, fill)` makes rows it lacks with `make` and gives each row coming
into view its item with `fill`. `wheel(dy)` scrolls; `offset` is the position in dips; `pitch`
is the row height.

The rail beside it is a [Scrollbar](/components/scrollbar/).
