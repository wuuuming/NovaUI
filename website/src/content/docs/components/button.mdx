`Button` is a `Row` that can be pressed. Its look in each state is the sheet's: `bg-hover`,
`bg-press`, `fg-disabled`, and `bg-lit` for a toggled state the app sets with `set_lit`.
`on-click: name` sends `Event::Click` with the action `name`; `set_disabled` turns it off.
