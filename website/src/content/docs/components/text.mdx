`Text "…"` or `text: $binding` gives the string. `type` takes a size, line height and weight from
the type ramp; `font-size`, `line` and `weight` set them one by one. `lines: 0` wraps without a
limit, `lines: n` ends the nth line with an ellipsis; `text-align` is `left`, `center` or
`right`. See [Text](/concepts/text/) for fonts and line breaking.
